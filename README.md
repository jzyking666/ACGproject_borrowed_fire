# 借火 · Borrowed Fire

**主网将在清晨迁走，旧区还有人等你交班。**

《借火》是一款单人三维动作解谜游戏。你需要搬运、旋转反射器，将危险的能量脉冲引向设备，再把它接成持续供电的回路。随着维修深入，还要在关闭发射器后，让同一颗脉冲继续维持设施运行，并安全抵达出口。

## 天亮之前 · 复网战役

从首页进入战役，先去「翻牌邮亭」。余照收到一袋盖着“地址不详”的退信。要印出完整的街名图，需要和沿线居民一起修好八个街区、四十八个地段。

每个地段有三张工单，可自行决定办理顺序。

| 工序 | 你要解决的问题 |
|---|---|
| 配线织盘 | 顺着有纹章的导线转动三档梭轮。中段测孔、绝缘要求、联动与离合会让一个调整影响另一端。先签收织盘，现场就能用配线校样试转一只镜座。 |
| 潮汐调度 | 逐拍查看船头、船尾和货物交接，提前、延迟发船或换道。检查完整周期，包括末拍与下一圈的首拍。先签收班表，现场可以预演立即或晚一秒出发的行走路线。 |
| 现场联检 | 在三维机房靠近轴座按 Q 或 E 转镜，按 N 查看各入口、目标出口和冷暖要求。甲路带真实负载，全线通过且甲路得电后，空手走到出口签收。 |

同一地段的三单签齐即可恢复该处供电。每区修通六段中的三段会为下游送电，双孔桥和刻字坡需要两条上游支线。回水塔总闸在其余 143 张工单签收后开放。途中可以换区或退出，首页进入战役后可续办最近一项。值班簿收录地段交班记录，也能导出本机用时。

**退信寻址**是邮袋里的八件未投邮件。相关地段复网后，拿现场交班笔记和信封上的印痕对照，分别盖出寄件地和收件地的章。投递成功可读到回信并收藏邮戳。从街区总图进入邮袋，投递进度随存档保留。

## 经典夜班故事

临时维修员余照接到一份撤网前的交接单：检查设备，签完回执，赶上末班车。调度员岑姨、维护机栈灯和苗圃看护员阿苇的通讯，却让图纸上的设备编号逐渐有了具体的收件人。

二十二个关卡通过原创关前、关后对话串联。每次接通回路，都会带来新的消息和交接记录。

## 返修值班台

首页的「返修值班台」有五封委托。开局时上一班已经安装好了线路。货梯工人说，顶楼的配电盘一直在走，他的电梯却一次也没停。你可以先在现场看一圈，再决定该搬哪一面镜。每封信都可以直接接单，签收后能读到报修人的回信。

走动、等待和开关来源免费。拿起、放下、旋转装置和编辑回声按次计数，达到信上的操作目标可获精修签收，超出仍可交付。每封信各自保存断点和最佳操作数；从首页「继续夜班」可以回到主线。

## 游戏内容

- **经典夜班共二十二关**：七间基础机房、五间中继站、四间回声花园、两张时序练习单，以及四间分光温室；基础机房之外均可自由选关。
- **双色路由**：同一棱镜对暖光与冷光沿不同斜面反射，让光路交替走向不同支路，或形成交叉的双翼回路。
- **组合解谜**：用反射器压住压板开启光闸，让脉冲经导光井跨越空间，再用换相器调节冷暖属性。
- **回声示教**：记录最长六秒的走位，让投影循环替你值守；组合双锁与反向光闸，安排“留守—让路”的时序。
- **回声调度**：查看路线与占板时间条，逐条调整播放相位和循环周期，安排一段回声完成多点接力。
- **可选挑战**：尝试只借一颗光、亲自启动供电接管，或让系统连续稳定运行；记录独立于通关星级。
- 屋顶下的阅档室、泵房和育苗室分别跟随对应接收环亮灯、开工和熄灯。出口旁的机械臂显示验收进度。
- **供电接管**：部分光闸可以先由压板启动，再让接收环维持，尝试用更少的设备完成交接。
- **未来推演**：隔离演算未来十二秒，拖动回放观察脉冲、供电与光闸时序；临时试验点便于比较布局。
- **完整撤销**：按 Z 或手柄 LB，恢复上次装置操作前的布局与脉冲状态，支持连续撤销。
- **夜班通讯**：带角色头像的短对话、两段章节收束与交接记录；支持跳过、回看和关闭自动播放。
- **观察与提示**：随时暂停查看按冷暖着色的光路，判断末端是墙体、光闸还是闭环；使用分步提示寻找思路。
- **视角与工单册**：在立体屋顶与俯视布局间切换；选关册提供章节导航与开工布局缩略图。
- **存档与记录**：自动保存、三个手动存档槽、存档文件导入导出和关卡成绩记录。
- **角色外观**：五种工作服、三种头饰与三种胸前标记，可自由组合并实时预览。
- **拍照模式**：隐藏界面、调整相机、切换景深，并将场景保存为 PNG。
- **键鼠与手柄**：支持键盘、鼠标和浏览器标准映射手柄。

## 本地运行

需要 **Node.js 22.12 或更高版本**，以及支持 **WebGL 2** 的桌面浏览器。

```bash
git clone https://github.com/jzyking666/ACGproject_borrowed_fire.git
cd ACGproject_borrowed_fire
npm ci
npm run dev
```

在浏览器打开终端显示的地址，默认是 `http://127.0.0.1:5173`。

## 单文件离线版

将整个游戏导出为一个可以双击打开的 HTML：

```bash
npm run build:html
```

生成文件位于 `release/borrowed-fire.html`。将这一个文件发给其他人，用支持 WebGL 2 的桌面浏览器打开即可离线游玩，无需安装 Node.js 或启动服务器。代码、样式、场景与剧情均包含在文件中。

本地 HTML 与网页版的浏览器存档可能不互通；可以在游戏的存档管理中导出／导入 JSON 来迁移进度。

## 维修规则

接收环获得脉冲后会暂时通电，脉冲会继续前进。从第三个机房起，必须让**同一颗脉冲重复经过接收环**，完成循环验证；供电超时后，验证会失效。

金色缓冲器会暂存脉冲，然后沿原方向释放。关闭发射器不会清除场内已有的脉冲，因此可以先搭建回路，再切断外部能源。

满足机房目标后，空手进入青色出口即可完成维修。受击会返回起点，但保留已经布置的装置。每关最多获得三颗星，分别对应完成、无伤和未使用提示；提示不会影响下一关解锁。

中继站引入三种装置：

| 装置 | 规则 |
|---|---|
| 压板与光闸 | 人或放下的反射器可以压住压板，对应光闸放行；光闸只拦脉冲，维修员可以穿过 |
| 导光井 | 相同字母的井成对传送脉冲，保持方向、身份与冷暖属性，不传送人 |
| 换相器 | 经过时互换暖光与冷光；带冷暖标记的接收环只接受对应脉冲 |
| 双色棱镜 | 暖光沿橙色斜面、冷光沿蓝色斜面反射；Q 交换两者方向，棱镜本身不改变颜色 |

按 Z 撤销会恢复操作时的整个回路，包括脉冲、供电与发射器状态。重试、读档或重新进入机房会清空撤销历史。

## 试验与推演

按 **空格 → E**（手柄 **X → A**）进入试镜台。任选一面已放下的活动镜，左右对照原布局和试转后的路线；暖光为实线，冷光为虚线。此处的闸门保持开台时的状态，试转只发生在图纸上。

按 **B** 打开未来十二秒的推演。角色保持原地，脉冲、回声和设备计时按当前状态演算；拖动时间轴或按左右方向键回放，查看供电和光闸时间条以及事件记录。选择一条现场读数可跳到对应时刻，并在三维场景标出位置。Esc 返回，继续维修。

按 **T** 记录临时试验点，调整后按 **V** 恢复布局、脉冲与回声。试验点仅保留在本次进入的机房中，重试或读档后清空；剧情与提示使用记录不会回滚。

第八关“留下一个人”和第十一关“无人值守”的光闸新增供电接管：压板可以启动线路，指定接收环通电后继续维持光闸，断电后重新需要压板。青绿色连线表示接管关系，可以尝试自己启动后离开压板。

## 回声花园

从首页进入“回声花园 · 新章节”。按 F 开始记录走位，再按一次结束，最长六秒自动完成。投影循环重放路径，最多保留两段；按 G 取消录制或移除最后一段。章节首关只提供一个投影位置。

投影只记录位置：它可以占据压板，不会拿东西、反射脉冲、触发受击或改变发射器。带 ◇ 的示教板只认投影；双锁要求两块板同时占据，橙色反向闸则在板空闲时放行。路径结束后投影回到起点。示教操作支持撤销，轨迹与播放进度随存档保存。

按 **L** 或通过暂停菜单打开回声调度。这里暂停关卡时间，显示每段路径、当前播放位置以及占据各块板的时间窗口。可以单独前后移动相位，也可以将周期调整为 0.5–6 秒；路线保持不变，播放速度随周期改变。周期按钮的步长可切换至 0.001 秒，手柄也能微调。所有修改支持撤销和存档。

“同步启动”将所有投影归零；来源在线且场内没有光时，会同时开始发射。已有脉冲不会被清除。同步后可按 B 推演，检查第一圈与后续循环是否都能按时通过光闸。

选关页附录的两张练习单进一步组合这些规则：“一个人的接力”要求同一投影依次启动两道闸；“每一圈都要交班”要求回声与整圈光路周期匹配，并在离网后持续运行。

## 可选挑战

工单中可以查看当前机房的两项可选挑战，结算和选关页会显示完成记录。它们不影响解锁与三星评价，可以在不同次维修中分别完成；使用提示也可以完成挑战。

“一颗就够”鼓励先关闭来源、规划布局再启动；部分接管关提供不留反射器压板的“亲手启动”；循环关的“经得起等待”需要所有接收环连续保持循环验证至少十二秒。

## 分光温室

首页可直接进入第三班“分光温室”。四张工单依次探索双色分支、交叉回路、跨区接管，以及冷暖支路与回声值守的组合。它们仍使用同一颗光，颜色和来向共同决定下一段路线。

双色棱镜的橙色、蓝色交叉斜面分别表示两种反射方向。可以拿放或旋转带活动底座的棱镜，固定件仍不能搬动。按 Space 查看从来源发出暖光后的完整双色静态光路；动态光闸和回声时序用 B 推演。

按 **Tab** 切换俯视布局，移动方向会与屏幕保持一致。再次按 Tab 返回立体；右键转动或 C 复位也会回到立体视角。暂停菜单提供同样的切换入口。

## 剧情操作

对话中按 Space、Enter 或手柄 A 继续，左方向键回上一句，Esc 或手柄 B 跳过。观看时暂停关卡计时，重试与读档不重复播放过场。

在选关、暂停或维修工单中打开“夜班通讯”，可回看已收录的入场与完工对话。旧存档会根据已有通关记录开放对应剧情，无需清空进度。设置中可以关闭自动播放；跳过剧情不影响关卡解锁与星级。

## 存档与设置

游戏进度保存在当前浏览器中。按 **J** 管理三个独立手动存档槽，也可以导出 JSON 文件，在其他浏览器导入继续游玩。清理站点数据会删除本地存档，重要进度可以通过导出文件备份。

主菜单的「设置与操作」和暂停菜单的「设置」都能打开同一张设置表。封面底部也可以直接点 English 或简体中文切换语言。更改即时生效，随本机存档保存。全屏跟随当前浏览器窗口。

| 分页 | 可调内容 |
|---|---|
| 语言与阅读 | 简体中文／English、三档字号、首次进入和完成机房时自动播放剧情、关键音效字幕。游玩途中可以切换语言。 |
| 调音台 | 总音量、配乐、现场音效和界面音量。后三轨可分别试听。点「试听场景」可轮听七段配乐，每次两小节，也可单独关闭背景音乐。 |
| 显示与动态 | 全屏、高画质、环境照明、游戏景深、减少动态效果、相机震动。低画质下停用辉光与景深。 |
| 操作 | 重新绑定四个移动键，调整鼠标和手柄的相机灵敏度、反向水平转动，以及手柄摇杆死区。方向键始终可用于移动。 |

首次点击或按键操作后，浏览器才开始播放声音。织盘用木质敲击和五拍循环，码头用簧音和摇曳的六拍，机房通电后会多出一条回应主旋律的声部。调低配乐，仍然可以靠音效辨认接收环得电、失电和拒收。切到其他标签页会暂停音频。

恢复默认设置会保留任务进度、成绩和三个存档槽。主菜单与暂停菜单中的「维修员」可以更换角色外观。

## 开发与构建

项目使用 **TypeScript、Three.js、Vite 和 Web Audio API**。游戏模拟与渲染分离，场景模型和纹理由代码生成，音效与配乐通过程序合成，界面使用系统字体。

| 命令 | 用途 |
|---|---|
| `npm run dev` | 启动本地开发服务器 |
| `npm test` | 运行游戏逻辑测试 |
| `npm run audit:campaign` | 检查战役题库与通关预算。可在 `--` 后附试玩 CSV 路径 |
| `npm run audit:levels` | 检查静态矩形替代解，报告输出到 `test-results/` |
| `npm run build:html` | 导出可双击游玩的单个 HTML，输出到 `release/` |
| `npm run build` | 类型检查并生成生产构建，输出到 `dist/` |
| `npm run preview` | 本地预览生产构建 |
| `npm run test:e2e` | 运行 Playwright 浏览器测试 |

浏览器测试首次运行前，需要安装测试用 Chromium：

```bash
npx playwright install chromium
npm run test:e2e
```

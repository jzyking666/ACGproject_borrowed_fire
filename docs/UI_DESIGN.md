# 界面设计与字体：第七区维修组

## 参考与取舍

查看以下游戏的设计说明和截图，从信息组织、主次与操作反馈提取方法，不复制图案、字体或素材。

- [Factorio 官方 GUI 开发日志](https://www.factorio.com/blog/post/fff-238)：强调中性克制的外观、文字对比度、可调字号及信息靠近对应对象。本项目对应功能优先、文字大小设置和场景设备编号。
- [Hades 界面截图索引](https://interfaceingame.com/games/hades/)：从截图观察主场景背景与菜单阅读顺序，设计左侧纵向菜单、右侧三维机房。这是对画面的分析，不是开发者官方设计主张。
- [Hollow Knight 官方展示](https://www.hollowknight.com/)：观察场景占比和 HUD 的克制程度，减少常驻文字，将说明放进工单与操作指南。没有使用其哥特字体或装饰纹样。

## 视觉规则

世界设定是旧设施的夜班维修，视觉集中在工装、设备编号、维修工单与高压警示。首页和所有内部页面共享深色面板、暖白文字与锈橙强调色。

| 元素 | 实现 |
|---|---|
| 字体 | 所有页面共用 `--font-ui`：苹方／微软雅黑／系统无衬线；数字沿用正文家族并启用等宽数字。等宽字体只用于按键，中文按键名回退到同一中文字体 |
| 配色 | 煤灰 `#15181b`、面板灰 `#1b2022`、暖白 `#e6e3d6`、锈橙 `#d79554`、通电绿 `#acd0ae`；危险红 |
| 标志 | 原创矢量断路环与闪电，无图片下载 |
| 面板 | 深色实底、细线、直角、清晰的行与表格，按钮保持平面；内部页面不再切换成另一套浅色表单 |
| 交互 | 主操作有填色和底边；焦点轮廓、菜单箭头、禁用状态 |
| 对比 | 暖白正文、清晰的灰色说明；不将正文处理成过小、过淡的装饰文字 |

## 各界面的职责

1. **主菜单**：标题、五项入口与七格进度。场景偏右，标题在左；移除长宣言与装饰英文。
2. **游戏 HUD**：左上关卡名，右上设备状态，下方操作。教学运行 20 秒后隐藏，观察时重现。编号投影到设备附近，观察时显示名称。
3. **维修提示**：默认收起，请求后打开可关闭的维修便笺；第三次显示参考轮廓。
4. **工单与存档**：16px 项目名、15px 正文、13px 时间标注；独立槽位与明确动作。
5. **维修员**：左侧服色／头饰／标记，右侧三维角色即时预览。
6. **拍照**：隐藏 HUD、暂停模拟，只保留相机说明、景深与导出。
7. **设置**：声音、画面、操作与阅读分组，标签、解释、当前值分列；点击后保持滚动位置与焦点。
8. **操作指南**：按键与动作按行对齐，使用说明列表，不靠全角空格排版；键鼠与手柄分栏，窄窗口改成单栏。
9. **暂停与结算**：复用同一标题、按钮、数字与文字层级。暂停常用入口单独成组，继续操作有明确焦点。
10. **确认、通知、失败页面**：覆盖导入、删除、提示、观察条、通知、启动失败等边缘界面，不单独使用另一套字体。

## 二级页面字体复查

上轮问题集中在内部页面的 10–13px 小字、偏淡颜色、550／650 等不统一字重和浅色表单观感。字体家族并没有一个额外的“AI 字体”文件；本轮统一继承关系和排版规则，使所有内容与首页一致。没有安装或下载新字体。

| 角色 | 100% 字号 | 字重 |
|---|---:|---:|
| 页面标题 | 30px | 700 |
| 选关名称 | 18px | 500 |
| 项目名、按钮、分组标题 | 16px | 500 |
| 说明正文、操作说明、表格 | 15px | 400／500 |
| 次要说明 | 14px | 400 |
| 日期与简短标注 | 13px | 400 |

字号使用 rem，跟随 100%／120% 文字设置。正文行高 1.65–1.8，不加装饰字距。Mac 优先苹方，Windows 优先微软雅黑；浏览器无法找到时使用系统无衬线，不请求外部字体服务。

长页面只滚动正文，标题和底部按钮保持可见。小窗口保留可读字号，通过滚动和换行适配，避免再次缩成细小文字。参考 [Factorio 的 UI 缩放复盘](https://www.factorio.com/blog/post/fff-277)，将文字与组件布局一起处理。上述实现是本项目的设计选择，没有声称复制参考游戏的具体字体。

## 可访问性与验收

提供 Tab 焦点、对话框焦点循环、手柄导航、字号 100%／120%、音量和减少动态效果。状态同时有文字／符号，不只靠颜色。

CSS 覆盖 1280×720 和常用桌面窗口。浏览器测试输出主菜单、机房和外观截图供复核；本机未安装测试浏览器，因此本轮没有实际截图对比。协调程度、遮挡和阅读舒适度以实机为准。

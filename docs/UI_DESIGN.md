# 第七区维修组的界面

余照在机房里看仪表，在值班台读工单，在邮亭拆信。视线落点和使用的物件一起变化。

## 画面与字体

| 场合 | 排版与用色 |
|---|---|
| 首页 | 左侧为套色印刷的夜班册封面。借、火二字分色，镜座剖面插图和右侧的三维场景呼应。复网战役、普通夜班和管理入口分开排。 |
| 机房与拍照 | 常驻读数用墨蓝搪瓷底和浅色字，操作集中在底边。机房名称、端口标记与镜座编号沿用同套招牌字和仪表字。打开工单时收起现场控件。 |
| 底图与工单 | 地图一栏看线路，一栏看当前街区。地段按行、工序按列查签收。配线图以线纹与符号区分线束，航班表逐拍标记冲突。现场联检同时标注入口、相位与线型。 |
| 书信与通讯 | 退信的封面与街段手记并排，返修人的叙述与技术附件分开。通讯采用四位角色各自的三色版画肖像，加上姓名、身份和对话。 |
| 设置与手册 | 设置的分组在左，当前值与机械触点在右。手册分键鼠、手柄、装置三页。暂停按现场工具、值班台、更换任务组织动作。 |

纸面使用暖纸色 `#eee7d7`、墨字 `#252823` 和朱砂 `#a43126`。深色仪表另取亮字与信号色。正文、细线和控件各有自己的明度。端口色相、航班冲突和已签收状态同时带有形状、文字或线纹。

宋体用于书名、地名、人物信文，Mac 优先宋体简，Windows 可回退到宋体。高频菜单和小字优先苹方或微软雅黑。表位、操作键和计数使用本地等宽字体，中文回退到黑体。程序绘制的三维字牌在创建贴图时读取相同的字族。所有字形由设备提供，离线文件无需字体服务，具体笔形会随平台变化。

## 设计参考

Lucas Pope 在移植《Papers, Please》时分析了文书、窗口和检查区域怎样分配空间，也讨论了小屏下字太小的问题。《借火》据此调整查阅顺序，查信时把证据留在眼前，长工单独立滚动。[开发日志](https://dukope.com/devlogs/papers-please/mobile/)

Gareth Damian Martin 在《In Other Waters》的访谈里谈到收音机等实体设备对操作台的影响。《借火》采用与自身操作相符的参照物，包括织盘档位、船班时刻表和接线端子。[作者访谈](https://www.avclub.com/in-other-waters-developer-interview)

章节字体与对话阅读层级也参考了《Pentiment》对故事文字与易读性的取舍。《借火》的中文字形来自系统字体，插画、肖像和邮戳按本作故事制作。[Obsidian 游戏介绍](https://pentiment.obsidian.net/)

# 双人组课程要求对照 · Topic 2 Interactive Game

公告第 2 页规定，双人组共同完成全部红色基础项，每人获得口头报告基础 15 分。黑色选做项由两人分别申报，每人最多 10 分，同一项仅一人得分。两人的口头报告各满分 25 分。Topic 2 允许使用 Three.js，禁止使用 Unity、UE5 一类完整游戏引擎及任何含可视化编程的引擎。多人游戏列为单独选做项。[课程公告，第 2、4 页](../ACG_Project_Announcement.pdf)

## 共同完成的基础项

| 公告要求 | 《借火》的实现 | 可复核的操作 |
|---|---|---|
| 场景布局、合理几何、纹理和材质 | 立体机房、屋顶、人物、反射器、电车车体与站台、程序地板纹理、金属和发光材质 | 转动相机观察反射器、接收环和工作台 |
| 动画 | 角色步态与转身、接收器转子、门闸、电车开门与发车、运行中的脉冲 | 搬起镜面移动，观察接收环得电、出口开启 |
| 主角控制 | 相机相对移动、慢走、拿放、旋转和开关发射器 | 用键鼠走近斜镜，搬运、定向反射 |
| 相机控制 | 可旋转、缩放、复位的三维正交相机和俯视切换 | 右键拖拽、滚轮、C 复位，Tab 对照俯视图 |
| 开始和结束界面 | 封面、关卡结算与夜班结局 | 从封面开工，开门交班并查看结果 |
| 完整可玩的游戏 | 原创设备规则、可解关卡、逾时和受击反馈、提示、重试、续玩 | 在真实关卡使接收环得电并空手抵达出口 |
| 用户手册或说明 | 游戏内操作指南、首关教学、分步提示及 README | 从设置打开操作指南，进场按 H 查看提示 |

玩法、渲染和输入由 TypeScript 代码连接。Three.js 提供绘图与后处理模块。开发和单文件构建步骤见 [README](../README.md)。

## 不重复的选做组合

以下两组用于检查项目覆盖与排练答辩。两位成员的姓名和真实贡献尚待填写。申报时按各自实际完成、能解释并能用源码核查的工作选择或调换，每个公告条目只占一格。

| 组合 | 公告黑项 | 分值 | 实现、操作与答辩要点 |
|---|---|---:|---|
| A | 碰撞处理 | 3 | 对墙角斜走，观察阻挡和贴边滑动，再让脉冲击中角色。说明圆与轴对齐矩形的最近点、移动子步、脉冲格内反射和受击恢复。见 [engine.ts](../src/engine.ts)。 |
| A | 保存及读取进度 | 3 | 持镜、脉冲在途时按 J 存入独立槽，改变布局后读取，再导出 JSON。说明快照中的角色、装置、脉冲身份、设备状态及导入校验。见 [storage.ts](../src/storage.ts)。 |
| A | 额外辅助界面 | 3 | 按 B 调阅未来十二秒，拖动回放定位故障，再回到原状态调整实物。说明推演为何保留原模拟的时间、位置和设备。见 [forecast.ts](../src/forecast.ts)。 |
| A | 同步音频 | 2 | 对比接收环得电、失电和错误色相的声音，调低配乐再次运行。说明游戏事件到 Web Audio 的触发、限频和分轨。见 [audio.ts](../src/audio.ts)。 |
| B | 环境照明 | 2 | 在同一机位开关环境照明，对比金属镜框的反射。说明 RoomEnvironment、PMREM 预滤与三维场景金属材质的关系。见 [view.ts](../src/view.ts)。 |
| B | 相机震动 | 3 | 用同一存档受击、放置装置，对比强弱，再关闭震动重试。说明强度累积、有界衰减和仅施加于相机的视口偏移。见 [feedback.ts](../src/feedback.ts)。 |
| B | 可自定义角色外观 | 3 | 在维修员界面切换服色、头饰和胸章，进入机房、读档复核。说明材质换色与几何替换的区别。见 [appearance.ts](../src/appearance.ts) 与 [view.ts](../src/view.ts)。 |
| B | 高级渲染特效 | 3 | 高画质下按 F2，在同一机位拍摄景深开启和关闭的两张图。说明 Three.js BokehPass 提供的深度与模糊处理、正交深度适配和主角在相机空间中的焦距。见 [view.ts](../src/view.ts)。 |

两组各列 11 分候选，按每人上限，各最多计 10 分。基础项与两组选做项合在一起覆盖两位成员各 25 分的口头报告候选范围。TA 会结合实际演示和每个人对实现的技术解释评分。若计划把清单外的高级技术计入成绩，公告要求在口头报告前联系 TA 商议可行性及标准。

## 可替换的公告选做项

| 黑项 | 分值 | 已有证据和仍需核实的事项 |
|---|---:|---|
| 多控制器 | 3 | 键鼠与标准映射手柄均有输入逻辑，覆盖菜单、移动、相机和交互。答辩前仍需接实体手柄验证整段操作。 |
| 难度递进 | 3 | 从单次反射到同一脉冲循环、离网交接，再组合光闸、双色和回声。选两段真实关卡展示玩家如何复用早先学会的规则。 |
| 友好且美观的布局 | 2 | 封面、全屏工单、设备读数、键盘焦点、中英文和大字排版可直接比较。若与“辅助界面”同时申报，分别演示视觉可读性与工具功能。 |
| 易安装或在线访问 | 3 | 运行 `npm run build:html` 可得到离线单 HTML，把文件复制到另一台支持 WebGL 2 的桌面浏览器试开即可演示。公开网址以实际部署结果为准。 |

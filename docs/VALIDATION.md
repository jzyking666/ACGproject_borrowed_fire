## 可选自动浏览器检查

由用户执行，第一条会下载 Chromium；游戏本身不依赖它：

```bash
npx playwright install chromium
npm run test:e2e
```

输出在 `test-results/`，包括菜单／游戏 720p 与外观截图。覆盖菜单移动恢复、外观、手动存档与错误文件、景深拍照、模拟手柄、720p 和设置解锁。模拟输入不能证明真实硬件手感；截图没有基准比对，需要人工查看。

GitHub CI 已配置同组检查，在 GitHub 临时机器执行并保留 `browser-results` artifact，不改变本机。目前尚无远程仓库和 CI 执行结果。
